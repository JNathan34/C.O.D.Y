# C.O.D.Y. 0.15.38

- **Plex and Overseerr by voice.** Ask who’s watching through Plex and check title availability through Overseerr. Cody recognizes more speech variations and carries availability follow-ups forward in the same chat. Local lookups run before any screen capture.
- **Media cards in the Island.** Plex activity shows who’s watching, the poster, playback progress, and an icon for the player device or browser. Media results expand into the Island’s curved layout with Cody above the cards.
- **In-app updates.** Click the Island update notice to open Settings. Select **Update and restart** to install silently and reopen C.O.D.Y.
- **WhatsApp and RGB Lighting.** Link your existing WhatsApp account and enable hands-free sending to verified contacts. Connect OpenRGB to let Cody react through selected lighting devices.
- **Task animations.** Cody uses the familiar thinking and speaking animations while working or replying.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
