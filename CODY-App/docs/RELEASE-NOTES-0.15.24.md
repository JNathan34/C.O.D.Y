# C.O.D.Y. 0.15.24

- **Make C.O.D.Y. easier to read.** Open **Settings → Accessibility** using the new blue figure icon. Adjust **Font size** from 90% to 150% or **GUI size** from 90% to 125%. The controls work independently and save automatically.
- **Read Island updates more comfortably.** Reply and task banners sit farther right in the compact Island.
- **Preview every task banner.** Open **Developer settings → Animation studio → Island task updates**. Choose one of 15 previews or use **Play all** to cycle through them.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
