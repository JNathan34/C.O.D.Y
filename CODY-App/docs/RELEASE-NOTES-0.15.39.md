# C.O.D.Y. 0.15.39

- **Built-in RGB Lighting.** C.O.D.Y. includes and starts the lighting helper for compatible devices. Say “Cody, set lights to green” or select `@RGB Lighting` in chat.
- **RGB plugin switch.** Open **Settings → Plugins → RGB Lighting** to turn the plugin on or off. C.O.D.Y. remembers your choice.
- **RGB Island.** Say “Open RGB control” or click **Open RGB controls** on the plugin card. Use the color wheel, presets, brightness slider, and device controls in the expanded Island.
- **Media Island branding.** Overseerr popups show the Overseerr logo and name. Plex popups show the Plex wordmark.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.

## Bundled lighting source

The installers include the upstream OpenRGB 1.1 portable helper.
