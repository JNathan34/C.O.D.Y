# C.O.D.Y. 0.15.13

- **Agent usage switch.** Turn off **Allow agent usage** in **Settings → Agents** to stop active agent work and block new tasks, routines and screen takeovers. Local commands remain available.
- **Desktop FPS.** Say “show FPS 24/7” to keep the widget pinned. When application FPS is unavailable, the widget shows the Windows desktop composition rate and labels it **Desktop**.
- **Discord commands.** Type or say “mute Discord,” “toggle deafen on Discord,” “share screen 2 on Discord,” or “share Firefox on Discord.” Sharing requires a call in the Windows desktop app. Enable accessible UI control and the relevant Audio control or Screenshots permission in C.O.D.Y. If a source needs review, finish selection in Discord’s picker.
- **Local memory.** Save, search and delete encrypted notes in **Settings → Memory**, or type “Remember locally that my name is Alex.” The **Local memory only** switch pauses Claude through HeyClicky on this PC because HeyClicky can add account memories to replies. Your sign-in stays connected.
- **Word guide.** The updated guide covers the new commands, settings and changes since the last guide update.

## Install or update

Use **Settings → Updates** in C.O.D.Y. or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs. Both installers are unsigned.
