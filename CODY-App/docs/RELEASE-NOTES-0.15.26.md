# C.O.D.Y. 0.15.26

- **Pick a capability in chat.** Type **@** to search enabled tools, connected plugins and installed skills. Select a result to add a removable chip and use that capability for the message. C.O.D.Y. reports if the selection is unavailable. [Issue #3](https://github.com/JNathan34/C.O.D.Y/issues/3)
- **Keep screen annotations until you clear them.** Drawings persist through clicks, taps, app switches and new replies. Mouse and touch input can reach the app beneath a noninteractive overlay. Use **Clear** or **Ctrl+Alt+X** to remove annotations. Browser highlights still follow their content as it scrolls. [Issue #37](https://github.com/JNathan34/C.O.D.Y/issues/37)
- **Type by default in Computer Use.** Text enters the focused field incrementally. Existing text and the clipboard are preserved during ordinary typing. Ask explicitly to paste. If focus changes or the field is protected, C.O.D.Y. stops. Firefox text entry uses foreground Computer Use. [Issue #38](https://github.com/JNathan34/C.O.D.Y/issues/38)

## Install or update

Use **Settings → Updates**, or download the x64 setup for Intel and AMD PCs or the ARM64 setup for ARM and Snapdragon PCs. With the 0.15.25 installer cached, the updater can reuse unchanged portions of the installer.
