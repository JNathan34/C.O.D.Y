# C.O.D.Y. 0.15.17

- **FPS widget.** FPS uses the same icon and text placement as the other island monitors. The island keeps its normal width, and FPS rotates through the shared widget when multiple monitors are pinned.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
