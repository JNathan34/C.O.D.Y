# C.O.D.Y. 0.15.35

- **Switch apps locally.** Say or type “Switch to Word,” “Bring Firefox to the front,” or “List open windows.” These commands use no agent quota. You can use an exact window title in quotes when several windows match.
- **Write in Word.** Ask C.O.D.Y. to introduce itself in the open document or type exact text. Text appears progressively, and the Island returns to idle when the edit finishes. “Just do it” can resume an earlier Word request in the same chat. When an earlier attempt may have inserted text, C.O.D.Y. checks that the document is blank before retrying.
- **Choose a Plex server after sign-in.** The server picker stays open after authentication, giving you time to select your server.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel/AMD PCs or the ARM64 installer for ARM/Snapdragon PCs.
