# C.O.D.Y. 0.15.9

This release includes all changes since 0.15.8.

## Improvements and fixes

- **Live chat replies:** keep spoken replies visible as they grow, preserve your position when reading earlier messages, and recover the final reply if a streaming update was missed.
- **AltGr quick message:** tap AltGr to send a saved phrase, defaulting to “done”. Change the phrase or disable the shortcut in Settings → Shortcuts. Quick messages preserve your draft and prevent duplicate sends; using AltGr with another key does not send a message.
- **CODY app icon:** replace the old HeyClick icon embedded in the native engine, including alternate icon resources Windows could still select in Task Manager.

## Install or update

Choose **C.O.D.Y-Setup-0.15.9-x64.exe** for Intel/AMD Windows PCs or **C.O.D.Y-Setup-0.15.9-arm64.exe** for ARM/Snapdragon Windows PCs. Both installers remain unsigned.

Existing installations can use **Settings → Updates** to download and restart. Conversations and settings are preserved.
