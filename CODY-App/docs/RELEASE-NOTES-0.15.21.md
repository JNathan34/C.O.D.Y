# C.O.D.Y. 0.15.21

- **Say the whole request in one breath.** After “Hey Cody,” C.O.D.Y. keeps the same microphone stream open and buffers your first words while speech recognition starts.
- **Leave Discord calls more reliably.** C.O.D.Y. recognizes more ways to say “leave the Discord call,” routes clear sound-alikes through its built-in disconnect command, and asks when the app name is ambiguous.
- **Get faster media controls.** Play, pause, skip and seek wake the Windows media worker as soon as the command arrives. More phrases such as “continue playback,” “skip this song,” and “turn the system volume down” run locally.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
