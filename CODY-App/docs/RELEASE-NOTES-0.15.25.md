# C.O.D.Y. 0.15.25

- **Choose your browser.** Use **Settings → General → Preferred browser** to follow Windows or select an installed browser, including Firefox from the Microsoft Store. C.O.D.Y. uses that choice for web links and browser tasks and tells you if the browser becomes unavailable. Firefox works with on-screen computer control. Background browser control uses the matching Chrome or Edge extension.
- **Find and change settings faster.** Use the search icon in the Settings header, or ask C.O.D.Y. to show a setting or change supported preferences. The Accessibility icon now matches the other Settings icons. Settings uses your mouse and keyboard for computer control, and the Agents page has fewer controls.
- **Choose your voice output.** In **Settings → Voice**, select a speaker or headset and set C.O.D.Y.’s voice volume up to 300%. The Memory page uses clearer wording for local memory and Claude Code.
- **Keep chat open and read code in chat.** Press **Ctrl+Alt+P** to pin or unpin chat. Code examples render as formatted blocks with language labels and copy controls.
- **Keep drawings with the right window.** Annotations follow supported content as it moves or scrolls and return when you switch back to the annotated window. The Clear button remains available while drawings are hidden. Press **Ctrl+Alt+X** to clear C.O.D.Y.’s drawings from any app.
- **See the result of quick commands.** Weather and similar quick commands skip generic reply banners. Brightness changes have their own Island card, and task updates are always available.
- **Smaller Windows installers and incremental updates.** The installers include update blockmaps so future updates can download changed portions when the previous installer is cached. Updates from 0.15.24 download the full installer once.
- **Updated Word guide.** The [capability guide](https://github.com/JNathan34/C.O.D.Y/blob/v0.15.25/docs/CODY-Complete-Capability-Guide.docx) includes refreshed screenshots and instructions.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
