# C.O.D.Y. 0.15.22

- **Follow C.O.D.Y. with the sound off.** Turn on **On-screen subtitles** under **Settings → Accessibility** to read spoken replies in a click-through overlay above the taskbar.
- **See what C.O.D.Y. is doing.** The Island shows live progress, requests for approval or input, and task results. Select an update to open the relevant chat, task or approval. Turn these updates off under **Settings → Accessibility → Island task updates**.
- **Ask about files in chat.** Paste an image or attach a document, PowerPoint, text file or picture. C.O.D.Y. answers directly in the conversation. Images appear inline, and supported files show a text preview you can open in chat.
- **See more examples.** The README shows new screenshots of C.O.D.Y. drawing on screen, highlighting controls and inspecting a frame-time spike.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
