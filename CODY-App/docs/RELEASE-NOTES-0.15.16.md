# C.O.D.Y. 0.15.16

- **Local memory backups.** In **Settings → Memory → Memory Backup**, export your notes to readable, unencrypted JSON and import them into private local storage. Imports skip duplicates and notes that look like credentials.
- **Hands-free wake.** Improve detection of quieter multi-word wake phrases, preserve up to two seconds of buffered speech during microphone handoff, and re-arm the detector after a wake arrives while C.O.D.Y. is busy.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
