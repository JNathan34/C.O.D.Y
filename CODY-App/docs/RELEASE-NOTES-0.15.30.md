# C.O.D.Y. 0.15.30

- **Work with Word from chat.** Select Word from the @ menu to type text, draft content, format paragraphs, or insert your chosen pictures. Document requests use the existing Word window and local Word commands. [Issue #41](https://github.com/JNathan34/C.O.D.Y/issues/41)
- **Build editable layouts.** Apply headings, labels, lists, fonts and spacing. Position pictures on the right with text wrapping, insert page breaks, save as DOCX, and export PDF.
- **Protect existing work.** Verify the document and selection before editing, preserve anchored pictures when revising nearby text, group edits for Undo, and confirm overwriting existing output files with a backup.
- **Find media plugins in the catalog.** Plex and Overseerr now have matching plugin cards, logos, connection status and expandable settings.
- **Recognise your preferred browser.** The browser picker shows each installed browser's Windows app icon.

Routine Word formatting and picture placement run locally. Drafting and understanding content use the built-in AI connection and its normal usage allowance.

## Validation

Verified formatting, picture wrapping, saving, reopening, PDF export and rollback in installed Windows Word. All 460 automated tests passed. Live AI drafting remains unverified because the isolated development profile is signed out.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
