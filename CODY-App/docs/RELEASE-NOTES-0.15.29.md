# C.O.D.Y. 0.15.29

- **Keep drawings attached while you scroll.** C.O.D.Y. keeps the original control or text range and moves the existing drawing with it. Drawings hide when their target is off-screen, minimised, or on another tab. Returning to the original target restores its drawing. [Issue #37](https://github.com/JNathan34/C.O.D.Y/issues/37)
- **Clear only the control you click.** Clicking a circled button or quiz choice reaches the app and dismisses that highlight. Other marks stay in place.
- **See skill mentions inline.** Mentions appear where you type them in chat and stay visible in sent messages and conversation history.
- **Simplify weather settings.** Removed the Default weather city field. Temperature units are still available in Settings.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
