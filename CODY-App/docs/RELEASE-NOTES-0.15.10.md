# C.O.D.Y. 0.15.10

Computer use now blocks physical keyboard and mouse input in both control modes. Press **Esc** to stop and take back control. C.O.D.Y.’s own input continues to work during the session.

Trackpad and touchscreen actions that Windows converts into mouse events are also blocked. Direct touchscreen input and native precision-trackpad gestures may still get through on installations without Windows UIAccess.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs. Both installers are unsigned.
