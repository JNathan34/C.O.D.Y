# C.O.D.Y. 0.15.8

This release includes all changes since 0.15.6, including the 3D fixes published in 0.15.7.

## New features and improvements

- **Updates in the island:** see checking, new-version notices, download percentage, ready-to-restart, installation and error states. Tap or press Enter on the status to open Settings → Updates. Listening, recording, games and finished timers keep priority. Downloads and restarts still require the existing buttons.
- **Expanded chat:** keep chat large during the current open session. Minimising restores normal size and pointer bounds; the next opening starts at normal size. Conversation and draft content remain intact.
- **One task interface:** prevent the legacy native task dock from opening on top-edge hover or native reopen requests. Background tasks remain available in C.O.D.Y.’s Tasks page.
- **Updated guide:** include the refreshed illustrated capability guide, update-status screenshot and getting-started instructions.

## 3D fixes included from 0.15.7

- Keep models and pointer input inside the visible model-window content area.
- Align the close button with the top-right of the title bar, including after moving.
- Increase scroll zoom to 10× the original camera magnification.
- Close both the background and model together.

## Install or update

Choose **C.O.D.Y-Setup-0.15.8-x64.exe** for Intel/AMD Windows PCs or **C.O.D.Y-Setup-0.15.8-arm64.exe** for ARM/Snapdragon Windows PCs. Both installers remain unsigned.

Existing installations, including 0.15.7, can use **Settings → Updates** to download and restart. Conversations and settings are preserved.
