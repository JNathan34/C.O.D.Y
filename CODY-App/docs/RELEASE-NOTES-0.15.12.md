# C.O.D.Y. 0.15.12

- Resize C.O.D.Y.'s pointer from 50% to 200% in **Settings → Cursor**.
- Choose a speaker or headset for C.O.D.Y.'s voice and voice cues in **Settings → Microphone**. **System default** follows Windows.
- Export or restore portable preferences in **Settings → General → Settings Backup**. The JSON file includes appearance, cursor, shortcut and voice preferences.
- New installations start with the Original Blue accent. Existing profiles keep their saved accent.
- The signed-out prompt in **Settings → Plugins** now says **Sign in to Claude Code**.
- Compact island status displays and game and recording controls no longer show hover tooltips. Recording errors appear in the interface.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs. Both installers are unsigned.
