# C.O.D.Y. 0.15.37

- **Speech-synced subtitles.** Each caption stays visible while Cody reads the line. A slower voice speed keeps it on screen longer. Turn on subtitles in **Settings → Accessibility**.
- **Monitor access.** Choose where the Island appears and which monitor Cody uses first. Limit screen viewing, screenshots, recordings and direct Computer Use to selected displays in **Settings → Permissions → Monitor access**.
- **Computer Use plugin.** Turn native mouse and keyboard control on or off from **Settings → Plugins**. Approved quick commands remain available when Computer Use is off.
- **Plugin icons.** Chrome and Edge have their own logos. The `@` picker shows branded icons for supported entries and focuses on plugins, skills and Computer Use.
- **Overseerr and Plex.** Ask for recent Overseerr requests to see their titles and status in chat. Use **Test connection** on the Overseerr plugin card. Plex understands more ways to ask who is watching.

## Install or update

Use **Settings → Updates**, or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
