# C.O.D.Y. 0.15.33

- **Window management.** Arrange two to four apps, set a custom two-window split, select an existing window by title, and move or resize windows. Explicit new-window commands are available for supported apps. A successful split now shows a confirmation.
- **Word.** Use an attached DOCX as a formatting reference and keep it through a follow-up question. Save documents with wrapped pictures, get a topic question for a generic blank-document request, and see concise explanations when a direct edit cannot run.
- **Drawing visibility.** Drawings keep their original app when C.O.D.Y. opens. Drawings without a trackable element can stay visible in the original view and hide when scrolling or switching context.

Single-display window placement and signed-in Word drafting were checked on Windows. Live second-display placement, the revised Word clarification round trip, and broader Firefox drawing behaviour remain open in [#40](https://github.com/JNathan34/C.O.D.Y/issues/40), [#41](https://github.com/JNathan34/C.O.D.Y/issues/41), and [#37](https://github.com/JNathan34/C.O.D.Y/issues/37).

Update through **Settings → Updates**, or download the x64 or ARM64 installer for your PC.
