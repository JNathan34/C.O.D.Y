# C.O.D.Y. 0.15.15

- **Smoother hide animation.** Ctrl+Alt+H, On hover and Activity only let the island fold back into the top edge before Windows hides it. Reopening mid-fold continues from the current shape.
- **Panel close.** Controls fade before the panel returns to the compact island.
- **Island visibility.** Find the setting under **Settings → Appearance → Island**.
- **FPS counter.** The pinned frame-rate readout sits inside the island and stays visible alongside other status cards.

## Install or update

Use **Settings → Updates** in C.O.D.Y., or download the x64 installer for Intel and AMD PCs or the ARM64 installer for ARM and Snapdragon PCs.
